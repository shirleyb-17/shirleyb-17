## ✩ things I've worked on

###  AI-powered SDLC

> *What if a business requirement could become the beginning of a software project?*

Building an AI-assisted software development workflow that works with
business requirements, RAG and LLMs to generate software artifacts.

```text
📄 BRD
 │
             ├── ⭑ extract
 │
           ├── ⭒ chunk
 │
             ├──✮retrieve
 │
             ├── 🖥 reason
 │
              └── ✩ generate
        │
        ▼
   💻 Spring Boot
      project
```

`Python` · `FastAPI` · `Gemini` · `LangChain` · `Qdrant` · `Spring Boot` · `Gradle`

---

### ⭒ Knowledge & RAG systems

Building retrieval-augmented applications that allow LLMs to work with
domain-specific knowledge rather than relying only on their training data.

```text
documents → chunks → embeddings → vector store
                                      ↓
question → retrieval → context → LLM → answer
```

`RAG` · `Embeddings` · `Vector Search` · `Agent Routing` · `LLMs`

---

### 🖥 Document Intelligence

Working with document ingestion and extraction pipelines that transform
PDFs and images into structured information.

```text
📄 document
      ↓
🌐 storage
      ↓
✮ extraction
      ↓
🖥 structured data
      ↓
💻 intelligent workflow
```

`AWS S3` · `Textract` · `FastAPI` · `Streamlit`
